Feature
Guess

2024.12 — 2025.06

基于强化学习的口令文本猜测框架， 将多维度密码特征外化为可学习的奖励信号。

↗ GitHub 查看

真实口令行为呈现出两个互补侧面：局部相似性（围绕少量"专家密码"做变体）与全局分布（频率和结构呈高度偏态与文化差异）。 FeatureGuess 将"与真实口令接近"的可度量侧面外化为学习信号，在共享的生成与训练协议下系统比较其约束效果。

Similarity
基于对比学习，捕获局部模式变体的相似度奖励器
Distribution
基于 VAE 建模整体统计结构的分布奖励器
Hybrid
融合二者优势的混合奖励器，微调生成器参数
⚡
实验结果：平均超越现有主流模型 5–10% 的猜测命中率
